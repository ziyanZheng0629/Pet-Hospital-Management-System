# 讯德 3.0 宠物医院全栈 Demo

本地 Web SaaS 原型，支持真实后端读写和 SQLite 持久化。无需安装运行依赖，使用 Node.js 内置 HTTP 和 SQLite。

## 启动

需要 Node.js >= 22.13（本机使用 v26.1.0）。双击 `启动Demo.cmd`，或运行：

```powershell
cd "E:\招聘工作\讯德3.0"
npm start
```

访问 http://127.0.0.1:4318 。默认仅监听本机，不发布到互联网。退出终端会停止服务；重新启动后数据保留，但需重新选择身份。

## 十分钟演示

1. 选择青禾宠物医疗、院长身份。
2. 新建宠物档案，再新建预约。
3. 在预约排班确认到店、开始接诊。
4. 在诊疗中心写病历，勾选收费服务，保存并开单。
5. 在收银台模拟收款，查看收据。
6. 在经营报表查看收款、收入构成并导出 CSV。
7. 在提醒与回访新建任务并模拟发送。体验会员计次卡和库存调整。
8. 退出，选择医生 / 前台 / 宠主体验对应视图。宠主固定关联演示宠物“团子”。切换星野医院验证独立数据。

## 已实现

- 多医院数据隔离、两门店筛选、后端角色权限、演示会话。
- 宠物与宠主建档、健康档案和历史病历、会员等级展示、计次卡核销。
- 预约创建、同医生同门店时段冲突检查、到店、接诊、取消和完成状态流转。
- 医生病历、服务项目开单、服务端计价、事务保存、重复开单与重复收费拦截。
- 收银、演示收据、实际订单统计和 CSV 导出。
- 库存入库/领用、负库存拦截、库存预警。
- 提醒任务、模拟发送、医院配置与操作日志。
- 自适应桌面和手机布局；医生/宠主使用同一网页的受限角色视图。

## 演示边界

演示入口允许自选角色，**不是生产身份认证**。没有真实支付、短信、TCCC、微信小程序、PACS、检验设备、AI 模型或旧讯德接口。提醒开关只保存配置，尚未实现自动调度。病历由医生手填，不提供自动诊断。会员充值、退款、计次卡购买、住院手术、药品批次及处方扣库等尚未实现。

参考页面的可见目录用于确定模块，未完整观看所有培训视频，也未宣称逐项复刻原软件。详见 `需求与依据.md`。

## 项目结构

- `server.js`：API、SQLite、数据隔离、角色权限与状态流转。
- `public/`：中文工作台界面，原生 HTML/CSS/JavaScript。
- `data/clinic.sqlite`：自动生成的本地数据库。
- `tests/api.test.js`：完整业务闭环、权限、隔离和无效操作测试。
- `.agents/skills/`：通过 find-skills 安装的技能。

```powershell
npm test
```

测试使用独立临时数据库，不改动演示数据。可用环境变量 `PORT` 和 `DATA_DIR` 指定端口和数据目录。重置演示时，停止服务后备份并移走 `data` 目录；下次启动自动重建种子数据。

## 走向正式 SaaS

下一阶段需确定真实医院业务规则与旧系统接口，增加正式账号认证、成员和门店授权、数据库迁移与备份、审计完整性、支付退款对账、处方库存事务、隐私管理和部署监控。当前 SQLite 版本用于单机 Demo 验证，不能直接作为公网生产 SaaS。
